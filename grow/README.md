# 原神养成计算

`#养成计算 刻晴` 计算到 90 级、天赋 10/10/10。`#养成计算 刻晴 等级89 天赋10 9 10` 指定目标，`#养成计算 刻晴 天赋10` 将三个天赋一起升至 10 级，计算所需前置突破。`#原神培养计算 雾切 50-80+` 计算武器的区间总需求，`80` 是未突破，`80+` 是已突破。

角色有指定起始等级时用公开目标和天赋 1/1/1。未指定时可用本人已绑定 UID 的存档，例如 `#养成计算 刻晴 档案2`。没有完整等级、突破和基础天赋记录时，卡片注明从公开的 1 级基线估算。武器默认从 1 级开始。此版本显示养成所需材料总数，计算和渲染均使用本地资料。

沿用 MIT 上游 `ProfileGrow.js` 的经验、突破和天赋成本，以及 `wiki/character-grow.html`、`wiki/character-grow.css` 的布局和原素材。已有主题目录由 `LOTUS_GENSHIN_GACHA_THEME_DIR` 指定。角色使用其原神元素底图，武器使用原版默认水元素底图。所需资料缺失时提示材料数据不可用。许可证见 [MIT](../panel/miao/LICENSE)。[旧版来源](https://github.com/MOPELotus/miao-plugin/tree/2860761836069af80bacee5cb85b6dd2e91ea0b0)
