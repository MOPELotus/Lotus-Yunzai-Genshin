# 原神角色面板

- `#更新面板`、`#更新全部面板`、`#米游社面板更新` 从绑定的国服角色更新面板并显示角色列表。
- `#面板`、`#角色面板`、`#面板列表` 读取本地面板。
- `#芙宁娜面板`、`#芙芙面板`、`#芙宁娜圣遗物` 和 `#芙宁娜武器` 查看角色、装备和属性。常见旧角色别名仍可使用。
- 命令末尾加档案号可选择档案，例如 `#更新面板2` 和 `#芙宁娜面板2`。沿用长 UID 的用法时，UID 需要与当前档案绑定的原神角色一致。

新版面板写入 `data/genshin/panels/<QQ>/<UID>.json`，可用 `LOTUS_GENSHIN_PANEL_DIR` 指定目录。旧版喵喵 `data/PlayerData/gs/<UID>.json` 可直接读取，通过 `LOTUS_GENSHIN_LEGACY_PANEL_DIR` 指定已有档案目录。首次更新后，旧面板中仍可使用的角色会一同保留，源档案保持原样。旧文件若缺少角色最终属性，属性栏显示横线。群排行由另外的功能处理。

用 `LOTUS_GENSHIN_PANEL_THEME_DIR` 指向有权使用的喵喵 `resources/` 目录。默认沿用已配置的原神 Miao 主题，读取原背景、角色、武器和圣遗物图。模板以 Skia 绘制，未配置的图像会保留对应的文本。

## 练度统计

`#原神练度统计`、`#面板练度统计` 或 `#练度统计` 汇总当前档案的本地角色练度，展示等级、命座、好感、三项天赋、武器等级和精炼、圣遗物套装和已核对的评分。例 `#练度统计2` 可选档案。列表沿用旧版等级、星级、基础天赋总和、命座、武器和好感的排序，每 48 名角色分页。旧米游社简档可显示查得到的条目，缺项显示横线或「暂无评分」。当前实现从 `#更新面板` 获取新数据，查看统计无需即时访问米游社。资源使用旧模板的原神底图、头图、好感、天赋皇冠和装备图。

`#天赋统计` 采用同档案的角色顺序，表格末两列显示周本材料和天赋书。`#今日天赋`、`#明日天赋`、`#周二五星天赋` 可按开放日或星级筛选，末尾可加档案号或 `档案2`。国服日期于北京时间 04:00 切换，周日可刷各类天赋书。素材和排期取自原神主题目录及固定的旧排期表，未确认的材料或开放日保留缺失状态。

## 每日素材

`#今日素材`、`#我的材料`、`#明日素材` 或 `#周二材料 档案2` 按地区列出所选档案已有角色的天赋书和已装备武器的突破素材。沿用国服 04:00 日界、旧地区排序和原素材卡。已达到当前突破阶段天赋上限的角色或满突破武器向后排并淡显。周日直接提示所有素材开放。可用 `#更新面板` 更新所选档案资料。

## 圣遗物评分

`#芙宁娜圣遗物` 展示旧喵喵评分规则、分件得分、总分和评级。角色流派沿用固定版本规则，包括依赖命座、武器、套装和最终属性的分支。旧档已有的完整主副词条可直接评分。评分所需字段缺失时会指出原因并继续展示已有词条，更新面板后可重试。

`#圣遗物列表` 汇总绑定档案中可评分的圣遗物，按旧版筛选规则排序并展示前 28 件。末尾加档案号可切换档案，例如 `#圣遗物列表2`。若旧档缺少评分流派需要的角色属性，目录中的完整旧数值表可用于复算。资料不足的角色暂不进入列表。

## 伤害估算

`#胡桃伤害` 使用绑定角色的面板，列出旧喵喵预设情景、期望和暴击数值。`#胡桃伤害2` 选择第二种情景查看词条替换对照及生效条件。末尾用 `档案2` 切换账号档案，例如 `#胡桃伤害2 档案2`。默认目标为 103 级小宝及 10% 基础抗性，实际游戏中的队伍、抗性和触发条件会影响结果。

旧档对照覆盖了夜兰、丝柯克、那维莱特、玛薇卡、钟离、纳西妲、雷电将军和枫原万叶等角色。丝柯克按原天赋规则增加战技等级。弓藏的固定重击减伤和盈满之实满层的固定攻击力降低按原武器说明计算，盈满之实的精通加成随精炼变化。个人伤害从所选档案的实际面板计算，另存的预设或共享记录仍可查看资料。

掠食者沿用旧版的冰元素满层情景，固定 66 点攻击力只对埃洛伊生效。命中的计算条件标明仅 PlayStation Network 生效，档案没有登录平台字段。

`#敌人等级90` 或 `#怪物等级90` 可按 QQ 设置 0 至 999 级的计算目标，同一 QQ 的原神档案共享偏好。用 `#敌人等级90 档案2` 可从已绑定的其他档案进行设置。设置保存在面板目录的 `preferences/<QQ>/1.json`。如需继承旧设置，可将 `LOTUS_GENSHIN_PANEL_LEGACY_REDIS_URL` 指向隔离 Redis 或 Valkey 副本，为两个旧键前缀授予 `GETRANGE` 读取权限。本地偏好优先，未设置时依次读取旧 `miao:user-cfg:<QQ>` 或 `genshin:user-cfg:<QQ>` 的 `char.enemyLv`。

普通详情图在装备下沿用旧版伤害表，列出暴击、期望与治疗等单值结果，目标与同档案的独立伤害命令一致。部分情景缺少数值时标为「数据不全」。没有可计算的情景时仍可查看原面板资料。

## 临时换装

`#芙芙面板换绫华武器` 使用同档案中绫华保存的武器。`#芙芙伤害2换绫华杯子 档案2` 替换同档两角色相同位置的一件圣遗物，并查看第二种旧伤害情景。也可使用「花」「羽毛」「沙漏」「杯子」「头」等旧位置名。指定 UID 时，目标与来源都须属于所选档案当前绑定的原神角色。

`#芙芙伤害2换绫华武器+杯子+头 档案2` 同时试换同一来源角色的多个部位。每个部位只可出现一次。任一部位缺失或武器种类不合时，整组试算停止。

连续使用「换」可为不同部位指定同档案里的不同角色，例如 `#芙芙伤害2换绫华武器+杯子换刻晴头 档案2`。同一部位若指定两个来源，整条命令不成立。

`#胡桃换灭辰`、`#胡桃换专武`、`#胡桃伤害2换90级精1灭辰`、`#胡桃换满精护摩` 或 `#胡桃换精5武器` 可用原武器名称或别名试算。只写名称时，必须能从本档案的已装备武器核对等级、突破和精炼。默认精炼与等级上限沿用旧规则。裸名须唯一适配目标武器种类，未知或歧义名称不会被换装入口接管。

结果标为临时换装，保留目标角色的元素底图和旧比较布局。资料不全时保留能核对的装备与基础属性。临时结果不保存到面板档案、预设或群榜。武器类型不合、来源角色或装备缺失时直接提示。

`#胡桃换80级` 或 `#芙芙伤害2换等级 95 档案2` 单独试算角色等级。原命令支持 1–90、95 和 100 级。目标与原等级相同时沿用原档突破，换到其他等级时按旧区间推导。试算保留原命座、天赋和装备，缺少目标等级的旧属性表时显示资料不足。

`#芙芙伤害2换0命换等级 95 档案2` 可同时试算角色等级和命座。两个换段可换序，天赋加成按所选命座计算，武器和圣遗物沿用当前档案。

`#芙芙伤害2换等级 95换天赋91312 档案2` 可同时试算角色等级和天赋显示等级，两个换段可换序。当前档案的命座和装备照用，试算中的天赋等级直接参与伤害计算。

`#芙芙伤害2换等级 95换绫华杯子+头 档案2` 可同时试算角色等级和同档一个来源角色的圣遗物，两个换段可换序。保留原武器、命座与天赋，缺件或来源跨档时整条停止。

`#胡桃换80级换90级精1灭辰 档案2` 可同时试算角色等级和显式武器等级或精炼，两个换段可换序。角色与武器分别按各自等级和原档突破计算，保留原命座、天赋和圣遗物。

同一条也可用 `#芙芙伤害2换等级 95换0命换天赋91312换80级精2武器换绫华杯子+头 档案2`。等级、命座、显示天赋、显式武器和同档圣遗物各写一段，顺序不限。可省略任意额外修改，圣遗物段只取一个来源角色。

独立命座试算可用 `#芙芙伤害2换0命 档案2`、`#胡桃换满命` 或旧数字、中文命座别名。读取本档案的真实命座和原始天赋，按指定命座重算天赋加成和旧伤害情景。装备、原档案与群榜均不写入。

同一条试算也可用 `#芙芙伤害2换0命换绫华杯子+头 档案2`。命座片段可以在换装片段之前或之后，所有装备来源都必须属于所选档案。任一来源或部位无法确认时，整条试算停止。

命座也可与一段指定等级或精炼的武器一起试算，例如 `#胡桃伤害2换0命换90级精1灭辰` 或 `#芙芙换精5武器换满命`。两段可以换序。武器名称或种类无法确认时，整条试算停止。

`#胡桃换90级精1灭辰换绫华花 档案2` 可同时试算显式武器和同档一个来源角色的圣遗物。两段可以换序，武器或指定部位无法确认时整条停止。

独立的天赋试算可用 `#芙芙伤害2换天赋91312 档案2` 或 `#胡桃换技能13 12 10`。`天赋`、`技能`、`行迹` 后依次填写普攻、战技和爆发的显示等级（1–15）。计算按输入的显示等级取倍率，保留档案的命座和装备。

`#胡桃换90级精1灭辰换技能13 12 10` 或 `#芙芙伤害2换天赋91312换精2武器 档案2` 可同时试算显示天赋等级和显式武器等级或精炼。两段顺序不限，保留当前档案的命座和圣遗物。

`#芙芙伤害2换0命换天赋91312换精2武器 档案2` 可同时试算命座、显示天赋等级与显式武器。三段顺序不限，每种操作只写一段，保留当前档案的圣遗物。

`#芙芙伤害2换0命换天赋91312换精2武器换绫华杯子+头 档案2` 也可同时试算四项。每种操作各一段，顺序不限。圣遗物须来自本档案同一角色，所有修改合在一次只读试算里生效。

`#芙芙伤害2换0命换天赋91312 档案2` 同时试算指定命座与天赋，两个换段可以互换顺序。输入的仍是显示等级，指定命座用于伤害情景以及天赋基础等级的回推。

`#芙芙伤害2换天赋91312换绫华杯子+头 档案2` 同时试算天赋和本档案同一来源角色的圣遗物。两个换段可以互换顺序，保留目标角色当前装备的武器与命座。

`#芙芙伤害2换0命换天赋91312换绫华杯子+头 档案2` 可同时试算命座、显示天赋等级和同档圣遗物。三段顺序不限，每种操作只写一段，保留目标角色当前武器。

## 群面板榜

`#芙宁娜排行` 和 `#芙宁娜圣遗物评分排行` 查询本群当前成员的角色榜。伤害使用原规则默认情景的期望值，目标固定 103 级。圣遗物按角色总分排序，最多展示 15 项，分数相同沿用旧榜的 UID 逆序。

`#芙宁娜双暴排行`（兼容「双爆」）按暴击、暴伤副词条加权，并计入双暴头部的主词条。`#芙宁娜词条排行` 按角色评分规则对全部副词条加权。两榜沿用 MIT 旧提交 `edae19cf` 中的 `getCritMark` 和 `getValidMark`，使用面板已核对的词条和当前评分权重，按原精度排序。先前只有伤害和圣遗物总分的摘要可在本群重新查看本人详情，登记这两项附加数据。

功能默认关闭。设置 `LOTUS_GENSHIN_PANEL_RANK_GROUPS=群号1,群号2` 后，已登录且当前档案已绑定角色的成员，在获准群聊主动发送 `#芙宁娜面板` 或 `#芙宁娜详情` 可登记本人记录。每个机器人和群单独存放卡片所需的摘要，默认目录为 `data/genshin/panel-ranks/`，可通过 `LOTUS_GENSHIN_PANEL_RANK_DIR` 指定。发榜前重新核验当前群成员和当前绑定关系。旧全局 Redis 榜可用于迁移核对，群榜入口从上文的主动登记开始收集。

计算沿用内置的固定版本喵喵角色、武器及圣遗物规则。角色与武器的等级属性和天赋倍率取自已配置的 Miao 主题目录。命令只读取本地面板和数值资料。旧表或面板缺项时提示缺失。部分情景资料不足时仍显示其他可计算的情景。
